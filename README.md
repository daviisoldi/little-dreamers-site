# Little Dreamers - Interactive English Learning 🌟

Uma plataforma web interativa desenvolvida para incentivar a aprendizagem lúdica do idioma inglês através de contos clássicos gamificados.

## 📖 Sobre o Projeto

O sistema oferece uma experiência imersiva onde os usuários navegam por mapas de histórias, desbloqueando capítulos interativos. Ao final de cada conto, um minigame é liberado para fixação do vocabulário aprendido.

📄 **Documentação e Apresentação:**
Acesse a [Apresentação do Projeto (PDF)](./docs/Little_Dreamers_Slide.pdf) para conferir todos os detalhes pedagógicos e técnicos do desenvolvimento.

**Contos Disponíveis:**
* 🐺 **Little Red Riding Hood:** Aventura na floresta com mapa interativo.
* 🧜‍♀️ **The Little Mermaid:** Exploração submarina.
* 🦊 **The Little Prince:** Jornada espacial pelos asteroides.

## 🎮 Funcionalidades (Requisitos Funcionais)

- **Navegação por Mapas:** Sistema de trilhas onde capítulos seguintes só são liberados após a conclusão do anterior.
- **Leitura Interativa:** Capítulos com textos em inglês fáceis de acompanhar e interface imersiva.
- **Minigames de Fixação:** Jogos de Caça-Palavras (Word Search) temáticos ao final de cada conto para reforçar o vocabulário.
- **Sistema de Progresso:** Salvamento do progresso local do usuário via `localStorage`, mantendo os capítulos desbloqueados.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica das páginas e mapas.
- **CSS3:** Estilização, animações (como os botões pulsantes) e responsividade para dispositivos móveis.
- **JavaScript (Vanilla):** Lógica de progressão de capítulos, controle de modais e motor dos minigames de caça-palavras.

## 🚀 Como Executar

1. **Acesso Direto:** Acesse a aplicação rodando online no [GitHub Pages](https://daviisoldi.github.io/little-dreamers-site/).
2. **Localmente:** 
   - Clone este repositório: `git clone https://github.com/daviisoldi/little-dreamers-site.git`
   - Abra o arquivo `index.html` em qualquer navegador web moderno.
   - Nenhuma instalação ou servidor local é necessário (aplicação estática).
